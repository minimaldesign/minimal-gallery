## Versioning

minimal gallery 2 is a rewrite of the 0.8 PHP app, so the four packages (fixed together in `config.json`) start at 2.0.0. Until launch they are betas: they start at `2.0.0-beta.0` and changesets is in pre mode (`pre.json`, tag `beta`), so every release is the next `2.0.0-beta.N`, published under npm’s `beta` tag, whatever the changesets’ bump types. At launch, run `pnpm changeset pre exit`; the next `changeset version` then gives `2.0.0`.
